Выбрать все одинаковые блоки одним щелчком

Выбор объектовSELECTSIMILAR· имя не локализовано; в меню — «Выбрать подобные» ~3 мин

На этаже 60 одинаковых блоков — извещатели, светильники, розетки. Все нужно перекинуть на другой слой, заменить или посчитать. Выбирать рамками мимо мебели — долго, по одному — вечность.

Приём

  1. 1Выделите один образец — например, блок извещателя.
  2. 2Правая кнопка → «Выбрать подобные» (или введите SELECTSIMILAR).
  3. 3В набор попадут все объекты того же типа с совпадающими свойствами; для блоков — то же имя и тот же слой.
  4. 4Параметр «Настройки» внутри команды задаёт, какие свойства считать совпадением: цвет, слой, имя и другие.

Попробуйте сами

Щёлкните любой дымовой извещатель, затем примените «Выбрать подобные» — и посмотрите внимательно, сколько выбралось.

сначала щёлкните извещатель-образец

Почему одиннадцатый извещатель не попал в набор — и как его всё-таки захватить?

Когда действительно полезно

  • •Массовые операции с одинаковыми блоками: слой, цвет, замена, подсчёт.
  • •Работает не только с блоками: «все такие же» тексты, размеры, штриховки — одним щелчком.

Когда лучше иначе

  • •По умолчанию должны совпадать слой и имя (SELECTSIMILARMODE = 130): такой же блок на другом слое в набор не попадёт, пока не поменяете настройки.
  • •Нужен выбор по произвольному условию, а не «как этот» — это уже БВЫБОР.

Можно выделить сразу несколько разных образцов — набор соберётся по каждому из них: все такие блоки плюс все такие тексты за один вызов.
