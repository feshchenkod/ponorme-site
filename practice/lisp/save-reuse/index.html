Сохранить навсегда и поделиться с коллегами

Старт команда: ТЕСТ ~4 мин

Команда отлично отработала — а после перезапуска AutoCAD её нет. Загруженный .lsp живёт один сеанс. Наведём порядок: один личный файл, автозагрузка и передача коллегам.

  • Держите все свои команды в одном файле — его проще автозагружать, переносить и отдавать.

Код

; мои-команды.lsp — личный набор для AutoCAD; сохранять в кодировке ANSI (Windows-1251)​(defun c:ТЕСТ ()  (princ "\nНабор на месте!")  (princ))​; «визитка» — печатается при каждой загрузке файла(princ "\nЗагружены мои команды: ТЕСТ")(princ)
мои-команды.lsp
— все свои команды складывайте в этот один файл — defun может быть сколько угодно
«визитка»
— строки вне defun выполняются сразу при загрузке — удобно печатать список команд, чтобы не забывать имена

Как запустить у себя

  1. 1Скопируйте код кнопкой выше и сохраните в файл с расширением .lsp — в кодировке ANSI (Windows-1251), чтобы русский текст не превратился в «????».
  2. 2Загрузите файл: команда ЗАГПРИЛ (APPLOAD) или просто перетащите файл в окно чертежа.
  3. 3Введите в командной строке: ТЕСТ

Пробуйте на копии чертежа. В AutoCAD LT работает начиная с LT 2024.

Файл с именем acaddoc.lsp AutoCAD подхватывает из папок поиска автоматически — этим пользуются и вредоносные скрипты. Чужой acaddoc.lsp не копируйте не глядя, а свои файлы храните в папке из списка доверенных.
