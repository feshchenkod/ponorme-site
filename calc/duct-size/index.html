Справка

Назначение и исходные условия

Подбирает воздуховод по расходу воздуха и принятой скорости — круглый из стандартного ряда диаметров или прямоугольный (одна сторона задаётся, вторая подбирается), а также решает обратную задачу: какая скорость получится в уже выбранном размере. Дополнительно считает эквивалентный по трению диаметр для аэродинамического расчёта.

Особенности методики и ограничения

Формулы

  • Требуемая площадь сечения: S = L/(3600·v), м².
  • Круглый воздуховод: d = √(4S/π); далее ближайший стандартный диаметр не меньше расчётного.
  • Прямоугольный: вторая сторона b = S/a, округляется вверх до типового ряда.
  • Фактическая скорость: v = L/(3600·S) — по фактической площади принятого сечения.
  • Эквивалентный по трению диаметр: dэ = 1,3·(a·b)^0,625/(a+b)^0,25, мм.
  • Гидравлический диаметр: dг = 2ab/(a+b), мм.

Ограничения

  • Рекомендуемые скорости — справочные (практика проектирования, АВОК), а не нормативные требования: верхняя граница ограничена шумом и потерями давления. Для систем противодымной вентиляции скорости и расходы определяются расчётом по СП 7.13130.
  • Соотношение сторон прямоугольного воздуховода по практике принимают не более 1:3: при большем растёт трение, расход материала и сложность монтажа.
  • Эквивалентный диаметр применяется только для определения потерь на трение — скорость и расход по нему считать нельзя.
  • Аэродинамический расчёт системы (потери давления в сети, местные сопротивления, подбор вентилятора) этим инструментом не выполняется.

Эквивалентный по трению диаметр прямоугольного воздуховода — аэродинамический расчёт по таблицам круглых воздуховодов (справочники, АВОК)

dэ = 1,3·(a·b)0,625/(a + b)0,25

Диаметр круглого воздуховода с теми же удельными потерями давления на трение при равном расходе — по нему прямоугольное сечение считают по таблицам круглых.

Гидравлический диаметр — гидравлика: 4·площадь/периметр

dг = 2·a·b/(a + b)

Используется в формулах чисел подобия (Re); с эквивалентным по трению диаметром dэ не совпадает — для подбора по таблицам круглых воздуховодов применяется dэ.

Частые вопросы

Как подобрать сечение воздуховода по расходу воздуха?

Требуемая площадь S = L/(3600·v), где L — расход (м³/ч), v — принятая скорость (м/с). Для круглого воздуховода диаметр d = √(4S/π), далее берётся ближайший стандартный диаметр не меньше расчётного. Для прямоугольного одна сторона задаётся по строительным ограничениям, вторая подбирается из типового ряда.

Какую скорость воздуха принимать?

Справочно: магистрали жилых и общественных зданий — 4–6 м/с, ответвления и подводки к решёткам — 2–4 м/с, воздухораспределители — 1,5–3 м/с (ограничение по шуму), магистрали производственных зданий — 6–12 м/с. Это практика проектирования, а не норматив: в системах противодымной вентиляции скорости определяются расчётом по СП 7.13130.

Зачем нужен эквивалентный диаметр прямоугольного воздуховода?

Таблицы и номограммы аэродинамического расчёта составлены для круглых воздуховодов. Чтобы ими воспользоваться для прямоугольного сечения, считают эквивалентный по трению диаметр dэ = 1,3·(a·b)^0,625/(a+b)^0,25 — потери давления на трение у такого круглого воздуховода будут теми же. Для расчёта скорости эквивалентный диаметр не применяется: скорость считается по фактической площади a·b.
