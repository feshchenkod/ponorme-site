Ток нагрузки и подбор автомата

Расчётный ток, полная и реактивная мощность по мощности и cosφ (1-ф / 3-ф) с подбором номинала автомата.

ГОСТ IEC 60898-1 · стандартный ряд номинальных токов автоматических выключателей

Считает расчётный ток электрической нагрузки по активной мощности и коэффициенту мощности для однофазной (220 В) и трёхфазной (380 В) сети, а также полную (кВА) и реактивную (квар) мощность из треугольника мощностей. По расчётному току подбирается ближайший стандартный номинал автоматического выключателя.

Формулы

  • Ток: 3-ф — I = P/(√3·U·cosφ); 1-ф — I = P/(U·cosφ), где U — линейное (3-ф) или фазное (1-ф) напряжение.
  • Полная мощность S = P/cosφ; реактивная Q = √(S² − P²); угол φ = arccos(cosφ).
  • Для двигателей потребляемая из сети мощность учитывает КПД: Pпотр = P/η.

Ограничения

  • Подбор автомата — только по расчётному току (нагреву), из стандартного ряда ГОСТ IEC 60898-1 (модульные автоматы до 125 А; номиналы выше — аппараты по ГОСТ Р 50030.2). Согласование с длительно допустимым током кабеля и выбор сечений — ПУЭ гл. 3.1 и 1.3, селективность и стойкость к токам КЗ проверяются отдельно.
  • Напряжение и cosφ задаёт проектировщик по паспорту нагрузки; для смешанной нагрузки используйте средневзвешенный cosφ. Подставляемые 220/380 В — распространённые в действующих сетях значения; ГОСТ 29322 задаёт номинальные 230/400 В — при необходимости укажите их в поле напряжения.

Вопросы и ответы

Как рассчитать ток по мощности для трёхфазной сети?

Ток трёхфазной нагрузки I = P/(√3·U·cosφ), где P — активная мощность (Вт), U — линейное напряжение (380 В), cosφ — коэффициент мощности. Для однофазной сети I = P/(U·cosφ) при фазном напряжении 220 В.

Какой автомат выбрать по расчётному току?

Номинал автомата принимается ближайшим не ниже расчётного тока из типовых номиналов ряда ГОСТ IEC 60898-1 (6, 10, 13, 16, 20, 25, 32, 40, 50, 63 А …; редкий номинал 8 А, также входящий в ряд стандарта, в подборе опущен). Это выбор по нагреву; селективность, стойкость к токам КЗ и согласование с сечением кабеля проверяются отдельно по ПУЭ (гл. 3.1, 1.3).

Зачем учитывать КПД (η)?

Для двигателей паспортная мощность указывается на валу; из сети потребляется больше на величину потерь: Pпотр = P/η. Ток считается по потребляемой мощности.

Почему для номиналов больше 125 А нет ссылки на ГОСТ IEC 60898-1?

ГОСТ IEC 60898-1 распространяется на модульные автоматические выключатели с номиналами до 125 А. Бо́льшие номиналы (160–630 А) — аппараты по ГОСТ Р 50030.2 (IEC 60947-2): выключатели в литом корпусе и воздушные. Такие номиналы помечаются отдельной подсказкой.
