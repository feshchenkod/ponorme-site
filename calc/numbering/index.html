Нумерация и адресация датчиков

Адреса извещателей на плане: подписи по щелчку, автоадресация вдоль линии ДПЛС с записью в атрибуты и поиск дублей — интерактивные LSP-команды для AutoCAD/nanoCAD.

1. Подпись и нумерация

Подписи: 1, 2, 3, …

Ёмкость ДПЛС одного С2000-КДЛ — 127 адресов. Предупреждение печатается в командной строке, нумерация не останавливается.

2. Размещение подписи

Режим «к блоку»: щелчок по вставке блока — подпись у его точки вставки со смещением, одинаково у всех датчиков. Отдельный слой создаётся автоматически: подписи легко скрыть или отключить на печать. Подпись — TEXT текущим текстовым стилем, выравнивание по центру. Смещение X/Y используют и режим «к блоку», и автоадресация подписью.

3. Автоадресация вдоль линии

Команда АДРЕС: выбираете линию ДПЛС (полилинию), щёлкаете возле конца, с которого вести отсчёт, и выбираете блоки рамкой — команда сортирует их вдоль линии и присваивает номера по порядку. Повторный запуск с нужного начального номера перенумеровывает участок.

Замкнутая полилиния считается кольцевой линией: отсчёт идёт от указанной точки по направлению отрисовки. Блоки без атрибута с заданным тегом считаются отдельно и о них сообщается. Проверка после адресации — команда АДРЕС-ДУБЛИ: разбирает подписи и атрибуты по заданному формату, дубли обводит кружками на слое ПРОВЕРКА-АДРЕСОВ, перечисляет пропуски номеров. Повторный запуск обновляет маркеры.

4. Скрипт

Один файл — три команды: нумерация по щелчку, автоадресация вдоль линии и поиск дублей («имя автоадресации»-ДУБЛИ).

;; ПоНорме (ponorme.ru) — нумерация и адресация датчиков.
;; НУМЕР — подписи адресов по щелчку; серия продолжается между запусками.
;; АДРЕС — автоадресация: выбранные блоки сортируются вдоль линии ДПЛС и
;; получают номера по порядку; запуск с нужного номера перенумерует участок.
;; АДРЕС-ДУБЛИ — поиск дублей и пропусков; находки обводятся на слое ПРОВЕРКА-АДРЕСОВ.
;; Загрузка: перетащить .lsp в окно чертежа или APPLOAD.
(defun pnrm:num-lbl (n) (itoa n))

(defun pnrm:num-place (pt lbl)
  (entmake (list (cons 0 "TEXT") (cons 8 "АДРЕСА") (cons 7 (getvar "TEXTSTYLE"))
                 (cons 10 pt) (cons 11 pt)
                 (cons 40 2.5) (cons 1 lbl) (cons 72 1) (cons 73 2))))

(defun pnrm:num-layer (nm col)
  (if (not (tblsearch "LAYER" nm))
    (entmake (list (cons 0 "LAYER") (cons 100 "AcDbSymbolTableRecord")
                   (cons 100 "AcDbLayerTableRecord") (cons 2 nm) (cons 70 0) (cons 62 col)))))

;; убрать старые подписи возле новой точки (список old собирает адресация)
(defun pnrm:num-clear (p)
  (foreach x old
    (if (and (entget (car x)) (< (distance (cdr x) p) 3.75))
      (entdel (car x)))))

(defun pnrm:num-put (e lbl / p)
  (setq p (mapcar '+ (trans (cdr (assoc 10 (entget e))) e 0) (list 3.0 3.0 0.0)))
  (pnrm:num-clear p)
  (pnrm:num-place p lbl))

;; разбор подписи «префикс + число + суффикс» в номер, иначе nil
(defun pnrm:num-parse (s / m i c ok)
  (if (and (> (strlen s) 0)
           (= "" (substr s 1 0))
           (= "" (substr s (- (strlen s) 0 -1))))
    (progn
      (setq m (substr s (1+ 0) (- (strlen s) 0)) i 1 ok T)
      (while (and ok (<= i (strlen m)))
        (setq c (ascii (substr m i 1)))
        (if (or (< c 48) (> c 57)) (setq ok nil))
        (setq i (1+ i)))
      (if ok (atoi m)))))

(defun pnrm:num-mark (p)
  (pnrm:num-layer "ПРОВЕРКА-АДРЕСОВ" 1)
  (entmake (list (cons 0 "CIRCLE") (cons 8 "ПРОВЕРКА-АДРЕСОВ") (cons 10 p) (cons 40 5.0))))

(defun c:НУМЕР (/ *error* doc def tmp pt es ent cnt n)
  (vl-load-com)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object)))
  (defun *error* (msg)
    (if n (setq pnrm:num-НУМЕР n))
    (vl-catch-all-apply 'vla-EndUndoMark (list doc))
    (if (and cnt (> cnt 0))
      (princ (strcat "\nПодписано: " (itoa cnt) ", следующий номер: " (itoa n) ".")))
    (princ))
  (setq def (if pnrm:num-НУМЕР pnrm:num-НУМЕР 1))
  (initget 4)
  (setq tmp (getint (strcat "\nНачальный номер <" (itoa def) ">: ")))
  (setq n (if tmp tmp def) cnt 0)
  (pnrm:num-layer "АДРЕСА" 1)
  (vla-StartUndoMark doc)
  (while (setq pt (getpoint (strcat "\nТочка подписи «" (pnrm:num-lbl n) "» (Enter — завершить): ")))
    (if (> n 127)
      (princ (strcat "\n** Номер " (itoa n) " больше лимита 127 — проверьте ёмкость линии.")))
    (pnrm:num-place (trans pt 1 0) (pnrm:num-lbl n))
    (setq cnt (1+ cnt) n (1+ n)))
  (setq pnrm:num-НУМЕР n)
  (vla-EndUndoMark doc)
  (princ (strcat "\nПодписано: " (itoa cnt) ", следующий номер: " (itoa n) "."))
  (princ))

(defun c:АДРЕС (/ *error* doc cs cur len closed p0 d0 rev ss ss2 i e e2 ed p q d lst old def tmp n cnt miss far lbl x)
  (vl-load-com)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object)))
  (defun *error* (msg)
    (if n (setq pnrm:num-АДРЕС n))
    (vl-catch-all-apply 'vla-EndUndoMark (list doc))
    (princ))
  (cond
    ((not vlax-curve-getclosestpointto)
     (princ "\n** Функций vlax-curve в этой САПР нет — автоадресация недоступна."))
    ((not (setq cs (entsel "\nЛиния ДПЛС (полилиния, отрезок, дуга, сплайн): ")))
     (princ "\nЛиния не выбрана."))
    ((vl-catch-all-error-p (vl-catch-all-apply 'vlax-curve-getendparam (list (car cs))))
     (princ "\nЭтот объект линией не является — выберите полилинию, отрезок, дугу или сплайн."))
    (T
     (setq cur (car cs)
           len (vlax-curve-getdistatparam cur (vlax-curve-getendparam cur))
           closed (< (distance (vlax-curve-getstartpoint cur) (vlax-curve-getendpoint cur)) 1.0e-6)
           d0 0.0)
     (setq p0 (getpoint "\nКонец линии, с которого начать отсчёт <начало линии>: "))
     (if p0 (setq p0 (trans p0 1 0)))
     (if closed
       (if p0 (setq d0 (vlax-curve-getdistatpoint cur (vlax-curve-getclosestpointto cur p0))))
       (setq rev (and p0 (> (distance p0 (vlax-curve-getstartpoint cur))
                            (distance p0 (vlax-curve-getendpoint cur))))))
     (princ "\nВыберите блоки датчиков: ")
     (if (not (setq ss (ssget '((0 . "INSERT")))))
       (princ "\nБлоки не выбраны.")
       (progn
         (setq lst nil far 0 i 0)
         (repeat (sslength ss)
           (setq e (ssname ss i) i (1+ i))
           (setq p (trans (cdr (assoc 10 (entget e))) e 0)
                 q (vlax-curve-getclosestpointto cur p))
           (setq d (vlax-curve-getdistatpoint cur q)
                 d (cond (closed (rem (+ (- d d0) len) len)) (rev (- len d)) (T d)))
           (setq lst (cons (cons d e) lst))
         )
         (if (not lst)
           (princ "\nПосле отбора блоков не осталось.")
           (progn
             ;; <= вместо < обязателен: vl-sort с < выбрасывает равные элементы
             (setq lst (vl-sort lst '(lambda (a b) (<= (car a) (car b)))))
             (setq def (if pnrm:num-АДРЕС pnrm:num-АДРЕС 1))
             (initget 4)
             (setq tmp (getint (strcat "\nНачальный номер <" (itoa def) ">: ")))
             (setq n (if tmp tmp def) cnt 0 miss 0)
             (pnrm:num-layer "АДРЕСА" 1)
             (setq old nil)
             (if (setq ss2 (ssget "_X" '((0 . "TEXT") (8 . "АДРЕСА"))))
               (progn
                 (setq i 0)
                 (repeat (sslength ss2)
                   (setq e2 (ssname ss2 i) i (1+ i))
                   (setq old (cons (cons e2 (trans (cdr (assoc 10 (entget e2))) e2 0)) old)))))
             (vla-StartUndoMark doc)
             (foreach x lst
               (setq e (cdr x) lbl (pnrm:num-lbl n))
               (if (> n 127)
                 (princ (strcat "\n** Номер " (itoa n) " больше лимита 127 — проверьте ёмкость линии.")))
               (pnrm:num-put e lbl)
               (setq cnt (1+ cnt) n (1+ n)))
             (setq pnrm:num-АДРЕС n)
             (vla-EndUndoMark doc)
             (princ (strcat "\nАдресовано: " (itoa cnt) ", следующий номер: " (itoa n) "."))
         ))))))
  (princ))

(defun c:АДРЕС-ДУБЛИ (/ doc ss i e ed a v p lst dup g n cnt gaps more x)
  (vl-load-com)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object)))
  (vla-StartUndoMark doc)
  ;; смыть маркеры прошлой проверки
  (if (setq ss (ssget "_X" '((0 . "CIRCLE") (8 . "ПРОВЕРКА-АДРЕСОВ"))))
    (progn (setq i 0)
      (repeat (sslength ss) (entdel (ssname ss i)) (setq i (1+ i)))))
  (setq lst nil)
  (if (setq ss (ssget "_X" '((0 . "TEXT") (8 . "АДРЕСА"))))
    (progn (setq i 0)
      (repeat (sslength ss)
        (setq e (ssname ss i) i (1+ i) ed (entget e))
        (setq v (pnrm:num-parse (cdr (assoc 1 ed))))
        (if v (setq lst (cons (cons v (trans (cdr (assoc 10 ed)) e 0)) lst))))))
  (if (setq ss (ssget "_X" '((0 . "INSERT") (66 . 1))))
    (progn (setq i 0)
      (repeat (sslength ss)
        (setq e (ssname ss i) i (1+ i) a (entnext e))
        (setq p (trans (cdr (assoc 10 (entget e))) e 0))
        (while (and a (= "ATTRIB" (cdr (assoc 0 (setq ed (entget a))))))
          (if (= "АДРЕС" (strcase (cdr (assoc 2 ed))))
            (progn (setq v (pnrm:num-parse (cdr (assoc 1 ed))))
              (if v (setq lst (cons (cons v p) lst)))))
          (setq a (entnext a))))))
  (if (not lst)
    (princ "\nМеток заданного формата не найдено.")
    (progn
      ;; <= вместо < обязателен: vl-sort с < выбрасывает равные элементы
      (setq lst (vl-sort lst '(lambda (a b) (<= (car a) (car b)))))
      (princ (strcat "\nМеток: " (itoa (length lst)) ", диапазон "
                     (pnrm:num-lbl (car (car lst))) " — " (pnrm:num-lbl (car (last lst))) "."))
      (setq dup nil)
      (foreach x lst
        (setq g (assoc (car x) dup))
        (if g (setq dup (subst (cons (car x) (cons (cdr x) (cdr g))) g dup))
          (setq dup (cons (list (car x) (cdr x)) dup))))
      (setq cnt 0)
      (foreach g (reverse dup)
        (if (> (length (cdr g)) 1)
          (progn
            (setq cnt (1+ cnt))
            (princ (strcat "\n  дубль " (pnrm:num-lbl (car g)) " — " (itoa (length (cdr g))) " шт."))
            (foreach p (cdr g) (pnrm:num-mark p)))))
      (princ (if (= cnt 0) "\nДублей нет."
        (strcat "\nДублей: " (itoa cnt) " — обведены кружками на слое ПРОВЕРКА-АДРЕСОВ.")))
      (setq gaps nil n (car (car lst)))
      (foreach x lst
        (while (< n (car x)) (setq gaps (cons n gaps) n (1+ n)))
        (if (= n (car x)) (setq n (1+ n))))
      (if gaps
        (progn
          (setq gaps (reverse gaps) more (- (length gaps) 30) i 0)
          (princ "\nПропущены: ")
          (foreach x gaps
            (if (< i 30) (princ (strcat (pnrm:num-lbl x) " ")))
            (setq i (1+ i)))
          (if (> more 0) (princ (strcat "и ещё " (itoa more) ".")))))
      (if (> (car (last lst)) 127)
        (princ "\n** Старший адрес больше лимита 127 — проверьте ёмкость линии."))
  ))
  (vla-EndUndoMark doc)
  (princ))

Как подключить и пользоваться
  1. Разово: перетащите скачанный .lsp в окно чертежа — или команда ЗАГПРИЛ (_APPLOAD) → выбрать файл → «Загрузить».
  2. Навсегда: в том же окне APPLOAD добавьте файл в «Приложения, загружаемые с автозагрузкой» (Startup Suite) — команда будет в каждом чертеже.
  3. Наберите НУМЕР, подтвердите начальный номер и щёлкайте по плану — каждый щелчок ставит подпись. Enter или Esc завершает серию; повторный запуск предложит продолжить со следующего номера.
  4. АДРЕС: укажите линию ДПЛС, щёлкните возле конца, с которого вести отсчёт (Enter — от начала линии), выберите блоки рамкой и подтвердите начальный номер — адреса встанут по порядку вдоль линии.
  5. АДРЕС-ДУБЛИ: без вопросов проверяет весь чертёж — дубли обводятся кружками на слое ПРОВЕРКА-АДРЕСОВ, пропуски перечисляются в командной строке.
  6. Ошиблись — завершите серию, удалите неверные подписи и запустите команду с нужного номера; откат — U (при необходимости несколько раз).
  7. Файл в кодировке ANSI (cp1251) — как принято для AutoLISP с русским текстом. nanoCAD загружает те же .lsp.

Справка

Назначение и исходные условия

Интерактивные команды для AutoCAD/nanoCAD, один .lsp — три инструмента. Нумерация по щелчку: щелчок по плану — подпись с очередным адресом, номер растёт сам. Формат подписи (префикс «1.», дополнение нулями «001»), начальный номер, шаг, слой и высота текста задаются в форме — скрипт генерируется под стандарт организации и переиспользуется на любых чертежах.

Автоадресация вдоль линии: команда сортирует выбранные блоки по положению вдоль полилинии ДПЛС и присваивает номера по порядку — подписью или записью в атрибут по заданному тегу. Конец отсчёта указывается щелчком, замкнутое кольцо нумеруется от указанной точки. То, что вручную занимает двадцать-сорок минут на линию, происходит за секунды; запуск с нужного начального номера перенумеровывает участок, старые подписи заменяются автоматически.

Поиск дублей: третья команда разбирает подписи и атрибуты по заданному формату, обводит дубли адресов кружками на отдельном слое и перечисляет пропуски в последовательности — быстрая проверка линии перед выпуском листа. Для адресных систем на С2000-КДЛ включён контроль ёмкости ДПЛС: после 127-го адреса команды предупреждают, не останавливая нумерацию. Начальный номер спрашивается при каждом запуске, по умолчанию — продолжение прошлой серии; ошибочную серию откатывает штатная ОТМЕНИТЬ (U) — по справке Autodesk U после LISP-команды может откатывать по одному шагу, тогда нажмите его несколько раз.

Частые вопросы

Как работает нумерация по щелчку?

Команда спрашивает начальный номер (по умолчанию — продолжение прошлой серии), дальше каждый щелчок ставит подпись и увеличивает номер на шаг. Enter или Esc завершает серию; итог и следующий номер печатаются в командной строке.

Как работает автоадресация вдоль линии?

Команда АДРЕС спрашивает линию ДПЛС (полилинию, отрезок, дугу или сплайн), точку возле конца, с которого вести отсчёт, и блоки. Блоки сортируются по положению вдоль линии и получают номера по порядку — подписью или записью в атрибут. Замкнутая полилиния считается кольцом: отсчёт от указанной точки по направлению отрисовки.

Как перенумеровать участок?

Запустите АДРЕС ещё раз: выберите линию и блоки участка, задайте новый начальный номер. В режиме атрибута значения перезаписываются; в режиме подписи старые подписи на слое подписей возле блоков заменяются новыми (это отключаемо в форме).

Что ищет команда поиска дублей?

АДРЕС-ДУБЛИ разбирает все подписи на слое подписей и атрибуты с заданным тегом по формату «префикс + число + суффикс»: дубли обводит кружками на слое ПРОВЕРКА-АДРЕСОВ, пропуски в последовательности перечисляет, старший адрес сверяет с лимитом. Повторный запуск обновляет маркеры.

Подписи — это текст или атрибуты блоков?

Нумерация по щелчку ставит однострочный текст (TEXT) на отдельном слое — работает с любыми блоками и без блоков. Автоадресация умеет и в атрибут: укажите его тег (например, АДРЕС) — значение запишется в блок; о блоках без такого атрибута команда сообщит, а режим «в атрибут, иначе подписью» подпишет их текстом.

Почему предупреждение после 127?

127 — ёмкость ДПЛС одного С2000-КДЛ. Команда предупреждает, но нумерацию не останавливает; лимит в форме можно изменить или отключить (0). Для второй линии обычно начинают новую серию с префиксом, например «2.».

Чем режим «к блоку» отличается от «в точку»?

«В точку» — подпись там, где щёлкнули. «К блоку» — щелчок по вставке блока, подпись встаёт у его точки вставки с заданным смещением: у всех датчиков одинаково, ровнее, чем на глаз. Автоадресация подписью использует то же смещение.

Работает ли в AutoCAD LT и nanoCAD?

Полный AutoCAD и nanoCAD — да. AutoCAD LT 2023 и старше — нет (там нет AutoLISP); в LT 2024+ AutoLISP появился и, по справке Autodesk, используемые vla-/vlax-функции поддерживаются (внешние COM-объекты — нет), однако на LT работа не проверялась. SCR-варианта нет: команды интерактивные.
