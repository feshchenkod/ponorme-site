Справка

Назначение и исходные условия

Считает требуемый расход приточного или вытяжного воздуха по кратности воздухообмена: L = n·V, где V — объём помещения, n — сколько раз в час воздух должен полностью замениться. По расходу и целевой скорости подбирается диаметр круглого воздуховода из стандартного ряда с пересчётом фактической скорости.

Особенности методики и ограничения

Формулы

  • Расход воздуха: L = n·V, м³/ч.
  • Сечение воздуховода: S = L/(3600·v); диаметр d = √(4S/π) — далее ближайший стандартный Ø не меньше расчётного.
  • Фактическая скорость в стандартном диаметре: v = L/(3600·S) — получается ниже целевой (сечение с запасом).

Ограничения

  • Кратностный метод — оценочный: СП 60.13330 требует определять воздухообмен расчётом по людям (норма наружного воздуха на человека), вредностям, влаге или теплоизбыткам. Справочные кратности дают стартовую оценку и применимы, когда профильный СП нормирует именно кратность.
  • Для санузлов и кухонь жилых зданий нормируются фиксированные расходы, а не кратность (таблица 7.1 СП 54.13330.2022: кухня с электроплитой — 60, с газовой — 100, ванная — 50, уборная — 25 м³/ч) — задайте расход напрямую через кратность n = L/V либо посчитайте по профильному СП.
  • Противодымная вентиляция (СП 7.13130) здесь не считается — там другая методика.
  • Типовые кратности в справочнике собраны по практике проектирования (АВОК, профильные СП) — перед выпуском проекта сверьте значение с документом для вашего типа здания.

Частые вопросы

Как рассчитать вентиляцию помещения по кратности?

Требуемый расход воздуха L = n·V, где V — объём помещения (м³), n — кратность воздухообмена (ч⁻¹) — сколько раз в час воздух должен полностью замениться. Кратность берётся из профильного СП для вашего типа помещения или из справочника типовых значений.

Почему расчёт по кратности — оценочный?

СП 60.13330 требует определять воздухообмен расчётом: по людям (санитарная норма наружного воздуха), по вредностям, влаге или теплоизбыткам. Кратность — упрощённый справочный метод: он даёт стартовую оценку и применяется, когда профильный СП нормирует именно кратность. Для санузлов и кухонь нормируются фиксированные расходы (м³/ч), а не кратность.

Какую скорость воздуха принимать в воздуховоде?

Для магистральных воздуховодов жилых и общественных зданий типово 4–6 м/с, для ответвлений и решёток 2–4 м/с (ограничение — шум), для производственных систем 6–12 м/с.
